# ShopNest - E-Commerce Website

## About the Project

ShopNest is a professional e-commerce website developed to provide users with a simple, attractive, and convenient online shopping experience. The website contains different product categories and provides features such as product browsing, product details, today's deals, best sellers, new releases, wishlist, shopping cart, checkout, and user account pages.

## Features

* 🛍️ Professional e-commerce homepage
* 🔍 Product search and category filtering
* 📦 All Products page
* 🔥 Today's Deals
* ⭐ Best Sellers
* 🆕 New Releases
* ❤️ Wishlist
* 🛒 Shopping Cart
* 💳 Checkout page
* 👤 User Account and Login
* 📱 Responsive design
* 🖼️ Product images and detailed product information
* ⭐ Product ratings and reviews
* 🔗 Product detail pages
* 🚚 Delivery and customer-support sections

## Main Pages

* **Home** - Displays the main ShopNest homepage.
* **Products** - Displays all available products.
* **Today's Deals** - Displays selected products currently available at discounted prices.
* **Best Sellers** - Displays popular and highly selling products.
* **New Releases** - Displays newly added products.
* **Product Details** - Provides detailed information about individual products.
* **Wishlist** - Allows users to manage their favorite products.
* **Cart** - Displays products added to the shopping cart.
* **Checkout** - Allows users to complete their orders.
* **Login/Account** - Provides user account functionality.

## Purpose

The purpose of ShopNest is to demonstrate the development of a modern e-commerce website using frontend web technologies and database-related tools. The project focuses on creating an organized, user-friendly, and professional online shopping platform.
